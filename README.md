# OSUS Interiors

Website for OSUS Interiors, Lahore.

- `website/` — the live site: static HTML/CSS/JS, no build step. Deploy this folder (set it as the root directory on Vercel / Netlify).
- `wordpress/` — the same design as a WordPress theme (`wordpress/osus`).

Local preview:

```bash
npx http-server website -p 5173
```
